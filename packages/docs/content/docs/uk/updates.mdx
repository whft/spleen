# Оновлення

Те, як ви оновлюєте Spleen, залежить від того, як ви його встановили. У будь-якому разі ви можете перевірити свою поточну версію в **Settings → Spleen → About**.

## Десктопний застосунок

Десктопний застосунок перевіряє наявність оновлень у релізах GitHub. Коли воно доступне, Spleen повідомляє вам, завантажує його, коли ви оберете, і встановлює при наступному перезапуску. Ви завжди керуєте процесом — нічого не встановлюється без вашого схвалення.

## Веб / CLI

Якщо ви встановили CLI, оновіть його з **About** кнопками перевірки та оновлення або з терміналу:

```bash
spleen update
```

Spleen визначає, як його було встановлено (npm, pnpm, yarn чи bun), і запускає правильне оновлення за вас.

## Застосунок для Android

Коли виходить нова збірка застосунку для Android, сповіщення пропонує її завантажити. Закриття сповіщення пропускає цю версію лише для сповіщення: **Settings → Spleen → About** показує кнопку **Download app** поруч із версією застосунку, доки ви його не встановите, а кнопка перевірки там перевіряє й застосунок. Інші кнопки оновлення в About оновлюють сервер, до якого підключений застосунок, а не сам застосунок.

Застосунок для iOS оновлюється через App Store.

## Сервер OpenCode

Spleen та OpenCode оновлюються окремо. Коли доступна нова версія OpenCode, Spleen пропонує оновити її й перезапускає сервер після цього. Див. [OpenCode Server](/uk/opencode-server/) про те, як цим сервером керують.
