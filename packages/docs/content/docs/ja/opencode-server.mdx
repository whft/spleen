# OpenCode サーバー

Spleen は OpenCode サーバーの上で動作します。デフォルトでは Spleen がサーバーを起動するため、何もする必要はありません。このページが必要なのは、すでに実行しているサーバーに Spleen を向けたい場合、または Spleen が起動するサーバーを管理したい場合だけです。

## Spleen がサーバーを見つける順序

Spleen の起動時、次の順序でサーバーを探します。

1. すでに起動済みのサーバーを再利用する
2. 外部サーバーを設定している場合は、そのサーバーに接続する
3. それ以外の場合は、自分のサーバーを起動して管理する

デフォルトでは、Spleen は割り当てられたポートで自分のサーバーを管理します。再起動後にポートが変わることがあります。Spleen はポート `4096` の別の OpenCode サーバーに自動接続しません。

## すでに実行しているサーバーに接続する

Spleen を起動する前に次を設定します。

```bash
OPENCODE_HOST=http://localhost:4096 OPENCODE_SKIP_START=true spleen
```

- `OPENCODE_HOST` — ポートを含む OpenCode サーバーの完全なアドレスです（`http://localhost:4096` のような値）。末尾にパスを付けてはいけません。
- `OPENCODE_SKIP_START=true` — Spleen に自分のサーバーを起動しないよう伝えます。

ポートだけを変えたい場合は、`OPENCODE_HOST` ではなく `OPENCODE_PORT` を設定します。

`OPENCODE_HOST` にポートがない、またはパスが含まれている場合、Spleen はそれを無視し、自分のサーバー起動にフォールバックします。期待した接続が行われなかった場合は、起動ログの `[config]` 警告を確認してください。

## CLI からサーバーを管理する

```bash
spleen status
spleen logs
spleen restart
spleen stop
```

`spleen` だけを実行すると、サーバーはバックグラウンドで起動します。ターミナルに接続したままにするには `--foreground` を追加します。

## ログイン時に Spleen を起動する

`startup enable` を使うと、ネイティブのユーザーサービスをインストールできます。Spleen は macOS では `launchd`、Linux では `systemd --user`、Windows では Task Scheduler を使います。

```bash
spleen startup enable
spleen startup status
spleen startup disable
```

UI を保護するには、サービスを有効化するときにパスワードを設定します。

```bash
SPLEEN_UI_PASSWORD='secret' spleen startup enable
```

ログイン時に起動し、デスクトップまたはモバイルクライアント向けに使うヘッドレスサーバーでは、`--api-only` と到達可能な host を含めます。

```bash
spleen startup enable --port 3000 --api-only --host 0.0.0.0 --ui-password secret
```

`startup enable` は現在の環境をサービスにスナップショットするため、同じシェルから `spleen` を起動した場合に近い動作になります。これにより、プロバイダートークン、`PATH`、SSH agent 設定、その他の CLI 認証/設定変数が利用できます。最小限のサービス環境にしたい場合は `--no-env-snapshot` を使ってください。

スタートアップサービスは `--port`、`--host`、`--ui-password`、`--api-only` を記憶します。CLI の restart と update restart は保存済み設定を再利用します。

別の Spleen アプリ向けに接続リンクを作成するには、次を使います。

```bash
spleen connect-url --port 3000 --server http://your-host:3000 --qr
```

`spleen connect-url --help` を実行すると、`--name`、`--lan`、`--server`、`--api-only`、`--ui-password`、`--qr` など、すべてのリンクオプションを確認できます。

その実行中サービスに対して、トンネルは独立して管理できます。

```bash
spleen tunnel start --port 3000
spleen tunnel stop --port 3000
```

トンネルを停止しても、サービスやアプリは再起動されません。

## "OpenCode is restarting"

サーバーの起動中または再起動中、Spleen は "OpenCode is restarting" 状態を表示し、準備が整うまでリクエストを一時停止します。これは起動直後や再起動直後には正常です。いつまでも消えない場合は、[OpenCode 接続](/troubleshooting/opencode-connection/) を参照してください。
