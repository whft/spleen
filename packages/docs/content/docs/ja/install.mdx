# インストール

作業スタイルに合ったアプリを選んでください。

- macOS、Windows、Linux 用のデスクトップアプリ
- CLI が動かす Web アプリ。スマートフォンアプリのようにインストールできます（PWA）
- VS Code 拡張機能。Cursor、Windsurf、Trae でも使えます
- iPhone と Android 用のモバイルアプリ（公開ベータ）

## デスクトップ

[ダウンロードページ](https://spleen.invalid/download/)または [GitHub Releases](https://github.com/spleen/spleen/releases/latest) から最新版をダウンロードして開きます。Linux 向けには `.deb`、`.rpm`、AppImage があります。

デスクトップアプリには [OpenCode](https://opencode.ai)（Spleen の土台になっている AI コーディングエージェント）が同梱されているので、ほかに何もインストールする必要はありません。

## Web + PWA

Web アプリを動かすマシンには [OpenCode](https://opencode.ai) と Node.js 24.14 以降が必要です。

```bash
curl -fsSL https://raw.githubusercontent.com/spleen/spleen/main/scripts/install.sh | bash
spleen --ui-password be-creative-here
```

CLI が表示した URL（通常は `http://localhost:3000`）を開きます。Spleen のセッション一覧が表示されれば準備完了です。すぐ開けるようにするには、ブラウザのアドレスバーにある「インストール」からアプリとして追加します。

## VS Code

[VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.spleen) から Spleen をインストールします。Cursor、Windsurf、Trae では [Open VSX](https://open-vsx.org/extension/FedaykinDev/spleen) からインストールします。拡張機能を使うには [OpenCode](https://opencode.ai) のインストールが必要です。インストール後、サイドバーに Spleen のビューが開きます。

## モバイル

iPhone アプリは TestFlight から、Android アプリは最新リリースからインストールし、コンピューターとペアリングします。手順は [モバイルアプリと PWA](/ja/mobile/) にあります。
