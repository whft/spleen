# Installation

Choisissez l’application qui correspond à votre façon de travailler :

- l’application desktop pour macOS, Windows et Linux
- l’application web lancée par la CLI, que vous pouvez installer comme une application de téléphone (une PWA)
- l’extension VS Code, aussi pour Cursor, Windsurf et Trae
- les applications mobiles pour iPhone et Android, en bêta publique

## Desktop

Téléchargez la dernière version depuis la [page de téléchargement](https://github.com/whft/spleen/download/) ou depuis [GitHub Releases](https://github.com/whft/spleen/releases/latest), puis ouvrez-la. Linux dispose de paquets `.deb`, `.rpm` et AppImage.

L’application desktop embarque sa propre copie d’[OpenCode](https://opencode.ai) (l’agent IA de code sur lequel tourne Spleen), il n’y a donc rien d’autre à installer.

## Web + PWA

L’application web a besoin d’[OpenCode](https://opencode.ai) et de Node.js 24.14 ou plus récent sur la machine qui l’exécute.

```bash
curl -fsSL https://raw.githubusercontent.com/whft/spleen/main/scripts/install.sh | bash
spleen --ui-password be-creative-here
```

Ouvrez l’URL affichée par la CLI (en général `http://localhost:3000`). Vous devriez voir la liste des sessions Spleen. Pour la garder sous la main, utilisez l’option « Installer » dans la barre d’adresse du navigateur et ajoutez-la comme application.

## VS Code

Installez Spleen depuis le [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=fedaykindev.spleen). Cursor, Windsurf et Trae l’installent depuis [Open VSX](https://open-vsx.org/extension/FedaykinDev/spleen). L’extension a besoin d’[OpenCode](https://opencode.ai) installé ; la vue Spleen s’ouvre ensuite dans la barre latérale.

## Mobile

Installez l’application iPhone via TestFlight ou l’application Android depuis la dernière version, puis associez-la à votre ordinateur. [Applications mobiles et PWA](/fr/mobile/) détaille les deux étapes.
