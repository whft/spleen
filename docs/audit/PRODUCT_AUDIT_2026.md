## 1. Architecture Verified Against Source

- **Desktop host**: `packages/desktop/src-tauri` (Rust, Tauri 2.12). Supervises `spleen-server.exe` inside a Windows Job Object (`JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`), manages single-instance focus, tray, dialogs, updater (`tauri-plugin-updater`), OpenSSH tunnels (`ssh.rs`), remote host probing/login, and LAN binding (`0.0.0.0:3721` when `desktopLanAccessEnabled` + `desktopUiPassword` are configured). No Electron runtime ships.
- **Sidecar server**: `packages/web/server/index.js` compiled via `bun build --compile` to `spleen-server.exe`. Owns OpenCode 2.3.0 lifecycle, SSE/WebSocket hub, SQLite recovery ledger (`recovery.sqlite3`), Session Goals, Limit Failover plugin, AI Teams DAG service, Agent Workflows sandbox, Agent Memory & Dreaming, Discord client/Gateway, UnknownCheats client/store, terminal PTY (`bun-pty` + embedded `rust_pty.dll`), and `spleen_control` / `spleen_web` / `spleen_workflow` / `spleen_memory` tools.
- **Shared UI**: `packages/ui/src` (React 19 + Tailwind v4 + Zustand + `@dnd-kit`). Shared across Web, Desktop (WebView2), VS Code webview, and Capacitor mobile.

## 3. High-Risk Release Issues Found & Fixed in This Pass

1. **Saved Remote Hosts Lost on Restart (`Broken` -> Fixed)**: `desktopHosts.ts` sent `{ input: { hosts, ... } }` to `desktop_hosts_set`, while `bridge.rs` persisted the outer object verbatim. Fixed unwrapping and added automatic migration on load.
2. **Missing Remote Host Probe / Login / Switch IPC (`Broken` -> Fixed)**: `desktop_host_probe`, `desktop_remote_password_login`, `desktop_switch_to_local`, `desktop_open_host_session`, and `desktop_browser_fetch_favicon` previously returned `not_implemented_in_tauri`. Implemented real Rust `reqwest`/window handlers in `bridge.rs`.
3. **OpenCode Zen Usage Auto-Continue Deadlock on Subagents & Missing Provider Scoping (`Partial` -> Fixed)**: Stopped Zen subagents deferred indefinitely behind `running` parents; non-Zen providers were not excluded from automatic `Continue.`; stopped sessions missed during SSE gaps were never enrolled. Fixed across `limit-failover/policy.js`, `session-recovery/reconciler.js`, and `session-recovery/runtime.js` with 63 passing tests.
4. **AI Teams Deadlock on Failed/Cancelled Dependencies (`Partial` -> Fixed)**: Tasks depending on a failed or cancelled task stayed `pending` forever, leaving the team permanently `active`, and cancelling a running task did not abort its OpenCode session. Added session abort, transitive `blocked` propagation, `@lead` escalation, and automatic unblocking on retry.
5. **Visual Clutter on Welcome & Teams (`UX Defect` -> Fixed)**: Removed floating 3D rings, floor circles, wireframe slabs, dust particles, and spinning 3D octahedra (`SpleenSpatialStage3D`, `SpleenMonolith3D`, `TeamConstellation3D`). Replaced with flat precision `SpleenLogo` and a functional `TeamExecutionGraph` supervisor/worker view.
6. **Stale Electron Architecture References (`Docs Drift` -> Fixed)**: Updated `AGENTS.md`, `CONTRIBUTING.md`, and `README.md` to match the real Tauri 2 desktop architecture.

## 4. Competitive Comparison (vs. OpenAI Agents SDK, Claude Code, Gemini CLI, OpenCode, Playwright)

- **Multi-agent orchestration (OpenAI Agents SDK / Claude Code Agent Teams)**: Spleen now combines OpenCode subagents, scripted VM `workflows`, `multirun` + Code Mode Fusion, and persistent `teams` DAG supervision. Next valuable step: automated worktree diff conflict preview + merge helper for Teams when `useWorktrees` is enabled.
- **Browser automation / Computer use (Playwright / OpenAI Computer Use)**: Spleen already has a clean `browser-control/provider.js` extension abstraction (`POST /browser-control`). Rather than rebuilding CDP inside Rust for WebView2, the cleanest high-reliability path on Tauri Windows is shipping a built-in Playwright/CDP browser-provider extension (semantic refs + screenshots + console/network logs + approvals) that plugs directly into the existing `browser-control` router.
- **Lifecycle Hooks (Claude Code / Gemini CLI)**: Spleen has server-side runtimes for `session-goal`, `limit-failover`, `auto-review`, and `scheduled-tasks`. Adding a declarative `.spleen/hooks.json` runner with explicit timeouts, non-recursive guards, and a Diagnostics execution log fits the existing architecture cleanly without creating another task engine.

## 6. Release Readiness Verdict

- **Ready for daily Windows desktop use and early public testers**: Core OpenCode chat/sessions, durable SQLite crash recovery + OpenCode Zen auto-continue across chats/subagents, Session Goals, Multi-run/Fusion, Agent Workflows, AI Teams, Memory/Dreaming, SSH key-based tunneling, LAN multi-device access, Discord/UC readers, and Tauri signed auto-updates (`whft/spleen` Releases) are wired, tested, and verified on Windows.
- **Remaining before broad general-availability public distribution**:
  1. Owner Windows Authenticode signing certificate (to clear SmartScreen warnings on other PCs).
  2. Built-in Playwright/CDP browser-control provider so `spleen_web` agent actions work on Tauri Windows (currently limited to iframe/popout without Electron's `<webview>`).
  3. Clean-machine install/uninstall/upgrade test on a fresh Windows 11 account without dev tools installed.
